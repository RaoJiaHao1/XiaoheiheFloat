# 小黑盒悬浮窗（XiaoheiheFloat）

一个常驻桌面的小悬浮窗，直接显示小黑盒社区网页 <https://www.xiaoheihe.cn/app/bbs/home>，
不用每次开浏览器、找入口。纯 C# + 原生 Windows 组件实现，没有 Electron、没有 Node、没有第三方 UI 框架。

## 快速上手（下载就能用，不需要懂代码）

1. 打开本仓库的 **Releases** 页面（GitHub 页面右侧栏），下载最新版的 `XiaoheiheFloat-便携版.zip`。
2. 把 zip 解压到任意文件夹（建议桌面或 D 盘，**不要**放进 `C:\Program Files` 这类受保护目录）。
3. 双击解压出来的 **`1-首次运行请点我.bat`**（第一次运行它会自动解除 Windows 的"网络来源"锁定，再启动程序）。
4. 如果弹出蓝色窗口"Windows 已保护你的电脑"：点 **"更多信息"** → **"仍要运行"**。这一步只在第一次出现。
5. 如果提示缺少组件，按提示安装一次即可：
   - .NET 10 桌面运行时：<https://dotnet.microsoft.com/download/dotnet/10.0>
   - WebView2 运行时：Win10/11 一般已自带，缺了去微软官网下载 "Microsoft Edge WebView2 Runtime"。

    装完后重新双击 `1-首次运行请点我.bat`。
6. 想彻底退出：窗口内**右键 → 退出**（右上角 X 只是收进托盘，不退出）。

常用快捷键：`Ctrl+Alt+H` 显示/隐藏，`Ctrl+Alt+T` 置顶，`F5` 刷新，`Ctrl+0` 回到"铺满"。

下载后建议先校验文件是否被改动（防止下载到被替换的恶意版本），方法见文末「完整性校验」。

## 技术栈

| 组成 | 用的是什么 |
| --- | --- |
| 界面 | WinForms（.NET 10 自带） |
| 内核 | Microsoft Edge WebView2（系统自带的 Edge 内核） |
| 窗口 | 无边框自绘标题栏，Win32 `WM_NCCALCSIZE` / `WM_NCHITTEST` 实现拖动与八向缩放 |
| 视觉 | DWM 阴影 + Win11 圆角，GDI+ 自绘图标、进度条、按钮 |
| 托盘 | `NotifyIcon` + 全局热键 `RegisterHotKey` |

WebView2 的托管程序集来自本机已安装的 Windows SDK（Windows Performance Toolkit 目录），
已随项目一起放在 `lib\` 下，**不需要联网下载任何 NuGet 包**。

## 运行要求

- Windows 10 / 11（x64）
- **.NET 10 桌面运行时**（`Microsoft.WindowsDesktop.App`）
- **Microsoft Edge WebView2 运行时**（Win10/11 一般自带；微软官网可免费下载）

### 底部缩放滑块

状态条右侧的缩放控件：`− [滑块] 适应 铺满`

**滑块的百分比是"相对铺满窗口"的倍率**，这是关键设计：

| 滑块 | 效果 |
| --- | --- |
| **100%（显示"铺满"）** | **左侧贴文铺满整个窗口**——右侧"热门社区/下载 App"栏不渲染，不裁切正文、不留白 |
| 115% ~ 300% | 在铺满基础上放大；页面按更窄的视口重新排版，文字换行、图片缩到容器宽度内 |
| `−` / `+` | 每次 5% |
| **`适应` 按钮 / `Ctrl+F`** | **幂等动作：把窗口全部交给左侧贴文**（倍率归 100% + 按 880 CSS px 单栏布局重算基准），点多少下都是这个结果 |
| 滑块上滚轮 / ←→ | 也能调 |
| 右键菜单 → 缩放倍率 | 100% / 115% / 125% / 150% / 175% / 200% / 250% |
| 右键菜单 → 跟随窗口宽度 | 开关：窗口变化时是否自动重算铺满基准（默认开） |
| `Ctrl+0` / `Ctrl+加号` / `Ctrl+减号` | 复位到铺满 / 放大 / 缩小 |

> 之前"适应"按钮的两个毛病已修：① 它是开关语义，和右键菜单的勾选项**互相抵消**（点一下等于没点）；
> ② 点开时只重算铺满基准、**不清倍率**，所以如果你之前放大了 150%，点"适应"只会重算基准、看着像"过度放大"。
> 现在它是纯动作：点一次必定回到倍率 100% 的铺满状态。

实际生效的缩放 = 铺满基准 × 倍率。日志里能直接看到这两个值：

```
fit preset: device=1300 targetCss=880 -> base=1.477     （宽窗口：基准放大，右栏移出窗口）
fit preset: device=440  targetCss=880 -> base=0.500     （窄窗口：基准缩小到单栏铺满）
```

窗口尺寸变化时倍率不变、只重算铺满基准，所以**你选的"放大多少"不会被窗口变化弄丢**。

> 注意：悬浮窗**不会**向页面注入修改布局的 CSS（例如 `*{max-width:100%}`、
> `meta[name=viewport]`）。这类"响应式补丁"会摧毁站点自身的固定宽布局、弹出层和图片容器，
> 曾导致"整个页面崩坏、图片显示不全"。页面样式保持原样，只做缩放。

### 窗口宽高自适应（"适应"）

小黑盒部分页面采用固定宽度布局：宽窗口下是"左贴文 + 右热门社区/下载栏"的双栏排版。
**"适应"的目标是只展示左侧贴文，把整个窗口都给它：**

把页面放到 **880 CSS px 的虚拟视口**里（实测该站点在 ≤900 CSS px 时切换为单栏紧凑布局，
右侧栏不再渲染），再等比放大到填满窗口。缩放倍率 = 窗口设备像素宽度 ÷ 880，
与页面内容无关，因此是**确定性、幂等**的动作，点多少次结果都一样。

实测（1300×800 逻辑尺寸）：

```
fit preset: device=1300 targetCss=880 -> base=1.477
fit check:  cssVp=880 kind=feed content=849 side=0 left=12
            （单栏正文列占满虚拟视口，右侧栏 side=0，即已不渲染）
```

窗口尺寸变化时按 150ms 防抖重算一次；**拖拽结束（`WM_EXITSIZEMOVE`）时再算一次**，
保证松手后一定按最终尺寸适配。放大倍率（滑块）在基准之上生效：
提高倍率后虚拟视口进一步变窄，站点会重新排版（文字换行、图片缩进容器），
而不是简单放大固定宽度页面制造横向滚动条。

实测（以 125% 系统缩放为例）：

| 窗口逻辑尺寸 | 结果 |
| --- | --- |
| 1300 × 800（宽） | 虚拟视口 880，右侧栏不渲染，贴文放大到铺满窗口（基准 1.477） |
| 440 × 780（默认） | 虚拟视口 880，单栏贴文缩小到铺满窗口（基准 0.500） |
| 吃不准时 | 点一下状态条上的「适应」或按 `Ctrl+F`，立刻回到"贴文铺满" |

不想让它跟随窗口变化，可以在右键菜单里取消勾选「跟随窗口宽度」，
之后缩放完全按你设定的倍率来。

### 菜单里能调的

- 置顶显示开关
- 窗口尺寸预设（手机窄栏 / 默认 / 宽屏 / 大屏），窗口大小和位置会自动记住
- 不透明度（100% / 95% / 90% / 85% / 75% / 60%）
- 缩放倍率（100% / 115% / 125% / 150% / 175% / 200% / 250%）
- 站内新窗口是在悬浮窗内打开，还是丢给系统默认浏览器
- 是否让网页显示浏览器默认右键菜单（默认关掉，右键就是本程序菜单）
- 用系统默认浏览器打开当前页

## 配置文件

位置：`%LOCALAPPDATA%\XiaoheiheFloat\config.json`（不可写时自动退回到程序目录 `Config\config.json`）。

```jsonc
{
  "X": 1346, "Y": 0,              // 上次的窗口位置（逻辑像素）
  "Width": 440, "Height": 780,    // 上次的窗口大小（逻辑像素）
  "Opacity": 1.0,                 // 不透明度 0.35 ~ 1.0
  "TopMost": true,                // 是否置顶
  "ZoomFactor": 1.0,              // 缩放倍率：1.0 = 左侧贴文正好铺满窗口，1.5 = 再放大 50%
  "FitToWidth": true,             // 是否跟随窗口宽度（关掉后铺满基准固定，不再随窗口重算）
  "HomeUrl": "https://www.xiaoheihe.cn/app/bbs/home",
  "OpenLinksInside": false,       // true = 站内新窗口也在悬浮窗内开
  "UserAgent": "",                // 自定义 UA，留空用 WebView2 默认
  "ExtraBrowserArguments": "--autoplay-policy=no-user-gesture-required"
}
```

窗口大小/位置按“逻辑像素”保存，换到不同缩放比例的显示器上观感一致。

## 排障

| 现象 | 原因 / 处理 |
| --- | --- |
| 提示“缺少 WebView2 运行时” | 装一次 Microsoft Edge WebView2 Runtime，或更新 Edge |
| 提示需要 .NET 运行时 | 装 .NET 10 Desktop Runtime |
| 页面白屏 / 加载失败 | 状态栏会显示具体原因（DNS、超时、连接被重置…）；按 F5 重试，或用菜单“用系统默认浏览器打开当前页”确认网络本身是否正常 |
| **Windows Defender 报毒 / 直接删掉 exe** | 见下面单独一节 |
| 程序异常退出 | 程序目录会生成 `crash.log`，里面有完整堆栈 |
| 想排查更细 | 用 `XiaoheiheFloat.exe --diag` 启动，程序目录生成 `diag.log`（记录了 DPI、窗口尺寸、网页内容宽度、自适应缩放计算过程等） |
| 想自动截图存档 | `XiaoheiheFloat.exe --diag --shot=D:\shot.png`，页面加载完成后自动截图并退出 |
| 想看某个尺寸下的排版 | `XiaoheiheFloat.exe --size=440x780 --shot=D:\shot.png`（`--size` 是逻辑尺寸，会覆盖已保存的窗口大小） |
| 想固定某个缩放做对照 | `XiaoheiheFloat.exe --zoom=0.5`（直接指定铺满基准，同时关闭跟随窗口） |
| 强制开启/关闭跟随窗口 | `--fit` / `--no-fit` |
| 想验证“解除锁定”是否生效 | `XiaoheiheFloat.exe --diag-unblock=某个文件路径`，会在程序目录写 `unblock-test.log` 并输出检测/解除结果 |
| 启动时不想被问“要不要解除网络来源标记” | 加 `--no-unblock-prompt` |

## 关于 Defender / SmartScreen 拦截

启动时弹出 **"Windows 已保护你的电脑 — SmartScreen 已阻止无法识别的应用"**，这是**误报**，原因是这类程序踩中了启发式规则，而不是真有恶意行为：

- 可执行文件没有代码签名证书；
- 程序里有 `SendInput` / `SetCursorPos` / `PrintWindow` 这类 Win32 调用（为了做无边框拖动缩放和自检截图），会被行为启发式盯上；
- **最关键的一条**：从压缩包/网盘/聊天工具拿到 exe 时，Windows 会给文件打上"网络来源"标记（Zone.Identifier / Mark of the Web），SmartScreen 对带这个标记的文件一律先拦再说。

### 怎么办

- 先按文首「快速上手」做：双击 `1-首次运行请点我.bat`（它会解除"网络来源"锁定后再启动），
  或在 exe 上右键 → **属性** → 勾选 **"解除锁定"** → 确定。
- 如果弹窗是 **Smart App Control** 阻止（不是 SmartScreen），进
  `设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制 → Smart App Control` 关闭该功能。
